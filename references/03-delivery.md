# 阶段5 交付验收清单（出版级 Word）

## 机械校验（pipeline 自动跑，须全绿）
- [ ] `zip.testzip()` = None（无损坏）
- [ ] document.xml well-formed（minidom 解析通过）
- [ ] `proof25 <file> --apply` 干跑 = 0 命中（红线收敛）
- [ ] who_docx.py verify 通过（结构/样式自检）

## 体积与结构对照（改后须不变，除明确新增）
- [ ] 段落总数、run 数、表格数与改前 inventory 一致
- [ ] `word/media/` 图片张数一致；图片仅换字节不换 document.xml
- [ ] 卷大小变化仅在图片压缩收益内（按面积分层抽样实测，勿按面积比估算）

## 排版规范（依据项目铁律）
- [ ] 字体：正文宋体、标题黑体
- [ ] 字号：一级标题 4 号(14pt)、二/三级小四(12pt)、正文五号(10.5pt)
- [ ] 缩进：正文首行 2 字符(420twips)，小标题顶格
- [ ] 对齐：标题居中、图注居中、表格标题居中
- [ ] 行距：图片段用 auto 单倍行距（避免 exact 压缩）；标题段前/段后适当
- [ ] **标题末尾一律无句号**（一/二/三级标题与 SectionTitle 小标题）
- [ ] 两套子标题约定勿混用：
  - SectionTitle 小标题（部位/临床特征/流行病学/鉴别诊断/免疫组化…）：深蓝粗体、顶格、无缩进。
  - 小小标题（正文流内分类/亚型标签）：(none) 段落 + 加粗 + 黑字 + 首行缩进 + 五号。

## 图片规范
- [ ] 只放镜下 HE 形态图（低/中/高倍）；**禁放大体标本照片、禁 IHC 图、禁带大段文字的截图**。
- [ ] 每案例 2～3 张 HE；图片与诊断一致，宁缺毋滥。
- [ ] 有效 DPI = 像素宽 ÷ 显示宽(英寸)；统一 **400 DPI 上限 + JPEG q95 + 4:2:2**；原 DPI 达标不重编码。
- [ ] 图上仅短图注(1～2 行)+小水印；无讲解性长文字。

## 终检
- [ ] 通读 3 个随机章节 + 全部图表，无漏译/误译/术语不一致
- [ ] 交付文件名含「中文」「出版级/交付版」及版本标识
