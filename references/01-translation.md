# 阶段1 翻译/意译 红线与铁律

## 0. 零容错铁律（适用于一切以文档为依据的内容）
1. **禁止主观臆造**：所有知识点、术语、数据都必须能在源文档追溯；无依据的不得写入。
2. **源文档为唯一依据**：综合英文原版书（须译为中文融入）；不得引入源外内容、不得自行发挥医学结论。
3. **全知识点全覆盖**：源文档每个章节 / 子标题 / 分类 / 疾病都映射到产出，不跳过小点。
4. **英文必须译为中文**：英文源内容融入时忠实译中并标注来源章节；不得保留大段英文或臆造译文。
5. **缺答案/不确定**：整条剔除或标"待确认"，**禁止猜测**。

## 1. 术语铁律（错一处即返工）
| ❌ 绝不写 | ✅ 必须写 | 备注 |
|---|---|---|
| 粘液 | **黏液** | 高频 |
| 尤文肉瘤 | **尤因肉瘤** | Ewing |
| 嗜睡细胞瘤 / 嗜睡瘤 | **冬眠瘤** | Hibernoma，ICD-11 XH1054 |
| 成纤维母细胞 | **纤维母细胞** | |
| 成釉细胞瘤 | **造釉细胞瘤** | |
| 不良预后 | **预后不良** | "不良预后因素/指标"合理，勿误改 |
| 伴有或不伴有 | **伴或不伴** | |
| 取样（病理标本语境） | **取材** | 统计"抽样/取样"可保留 |
| 淡嗜酸性 | **浅嗜酸性** | pale eosinophilic |
| 两染性 | **嗜双色性** | amphophilic |
| 黏液腺癌 | **黏液性腺癌** | mucinous adenocarcinoma 必带"性" |
| 黏蛋白 / 黏液 / 黏液性 | 三者不可混用 | 黏蛋白=mucin(糖蛋白)；黏液=mucus(分泌物)；黏液性=mucinous(形容词) |

**免疫组化「膜」位置铁律**：部位词(膜/胞质/核)作主语，程度词不得插在部位词与「阳性/染色/表达」之间。
- ✅ 膜中等或强阳性 / 膜强CD99表达 / 核膜阴性
- ❌ 中等或强膜阳性 / 强膜性CD99表达

**发病率分母「人年」→「人/年」**（斜杠不可省）：`每100 000人年`→`每100 000人/年`。

**年龄「第X个十年」口径**：第N个十年=(N−1)×10 ～ N×10−1（第一个十年=0～9岁）。必须回英文原版逐条核对，不可机械套公式。

## 2. 标点与符号规范（全文档适用，不区分中英文）
1. **运算符号用中文符号**；但 `+` 在 IHC 等病理语境不是运算符号（如 `CK5/6+`），保留不动。
2. **数字范围用全角波浪号 `～`**：`3～10`、`第1～3章`、`约40～60%`（禁用 `-`、`~`、`–`、`—`）。
3. **全部中文标点**：`，。；：！？（）【】《》""''`；禁用英文标点。
4. **标点前后禁止空格**：`（选项A）` 而非 `（ 选项A ）`；英文缩写与中文标点相邻亦不加空格（`S-100阳性`）。
5. **禁止任何来源标注**：解析/精讲/考点等正文不得出现 `（来源：…）`、`（依据：…）` 等格式。

## 3. 不译清单（优先级最高，原样保留）
基因名（MDM2/FUS/EWSR1）、抗体名（S-100/CD34/desmin/Ki-67/p53）、数字、分期、分级、ICD-O/ICD-11 编码、HGVS 命名（`NM_004235.6:c.1322A>C`、`p.(Val600Glu)`）。

## 4. 翻译腔清除（阶段3 润色重点）
- 被动态→主动态；"进行X检测"→"检测X"；"表现出X"→"X"。
- 长定语前置→中文叙事重组；>25 中文字必拆句。
- "相关"滥用→"相关"仅表 correlation；"关联研究"受保护不改。
- "监测"→"随访"；"报告"(文献叙述义)→"报道"（病理报告义受保护）。
- "它们"→"其"（句首亦可，医学文中可接受）；"中至高"→"中或高"。
